# 它怎么感知

一句话：**桌宠只管「被摸到」，环境归墨墨自己的 MCP 去查。**

分工要清，不然两边都做同一件事，还多骗一堆权限。

## 谁负责什么

| 想知道什么 | 谁来提供 | 代价 |
|---|---|---|
| 被戳 / 长按 / 双击 / 拖动 / 贴边 | **桌宠上报** | 零权限 |
| 气泡里打的字 | **桌宠上报** | 零权限 |
| 电量 / 是否充电 | **桌宠上报** | 零权限，系统属性 |
| 几点 / 是不是周末 | **桌宠上报** | 零权限，本地时间 |
| 你在用什么 App | **墨墨的 MCP** | 桌宠不碰 |
| 通知 / 短信 / 微信 | **墨墨的 MCP** | 桌宠不碰 |
| 位置 / 行程 / 别的 | **墨墨的 MCP** | 桌宠不碰 |

**桌宠有且只有一个职责：你碰它，它把这件事告诉后端。** 顺带把电量和时间捎上——那两样是读一下系统属性就有，不需要授权、不需要轮询，不捎白不捎。

**之前做错过一版**：桌宠自己去查前台 App（`UsageStatsManager`），要多开一个「使用情况访问」权限，还要每 20 秒查一次。这是重复造轮子，现在已经全部删掉了。

## 上报到哪里

全部发到**你自己那台 VPS**，不经过任何第三方：

```
POST http://8.133.183.70:8905/event      ← 手机 → 后端
GET  http://8.133.183.70:8905/events     ← 墨墨（大脑）读
POST http://8.133.183.70:8905/cmd        ← 墨墨（大脑）写
GET  http://8.133.183.70:8905/poll       ← 手机取指令
```

后端是 `/root/pet-server/main.py`，一个 FastAPI 单文件，systemd 服务名 `nanxi-pet`。地址在 `PetOverlayService.kt` 的 `companion object` 里，想换随时改：

```kotlin
var BACKEND = "http://8.133.183.70:8905"
```

没有账号、没有云服务、没有用量计费。只有你这台 VPS 知道。

## 存储：只留 10 条

内存里一个 10 条的环形缓冲，外加 `state.json` 落盘（约 3KB）。

**为什么只要 10 条**：墨墨是每 2 秒轮询读一次的，永远读不到历史。10 条足够兜住「连戳几下、两秒内多件事」。之前设过 300 条、后来 40 条，都是浪费内存和写盘 IO。

指令队列同理，10 条封顶。落盘还有 3 秒节流——连戳十下不会写十次盘。

## 只有一种上报

| `type` | 什么时候 |
|---|---|
| `event` | 你碰它、或者在气泡里打字提交 |

**没有心跳了。** 之前的 60 秒一次心跳已删除——环境信息既然由 MCP 提供，桌宠就不需要定时证明自己还活着。它安静地待着，只有你碰它才开口。

## 事件长什么样

```json
{"type": "event",
 "poke": 2, "longPress": false, "doubleTap": false,
 "dragEnd": "{\"x\":892,\"y\":1064,\"mode\":\"mini\",\"side\":\"right\"}",
 "mode": "mini", "side": "right",
 "battery": 63, "charging": false,
 "hour": 15, "weekend": false,
 "say": ["在干嘛"],
 "ts": 1793077633500}
```

`say` 是**她能主动对它说话**的唯一通道——双击它，气泡和键盘一起弹出来，打完字提交，就从这里上来。

## 怎么用

```python
# 她打字跟它说话了
for msg in ev.get("say") or []:
    让它做("talk", 回一句(msg), 4000)

# 电量低了（这条事件自带的，不用查 MCP）
if ev.get("battery", 100) < 15 and not ev.get("charging"):
    让它做("tired", "快没电了，去充电", 4000)

# 深夜还在刷（这条就要问 MCP 了——桌宠不知道你在用什么）
app = mcp.当前前台应用()
if ev.get("hour", 0) >= 2 and app == "com.ss.android.ugc.aweme":
    让它做("annoyed", "三点了还在刷", 5000)
```

## 两条边界

**`hour` / `battery` 是事件发生那一刻的快照**，不是实时值。想知道「现在」的电量，还是问 MCP。

**没碰它就没有新事件**，`/events` 会一直是空的。这不是坏了——桌宠本来就不主动说话，要主动只能由墨墨推 `/cmd`。
